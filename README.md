# Issues Reporting Outlet (IRO)

## Project Description
IRO is a web-based prototype designed to help students and residents around Adekunle Ajasin University report community problems such as bad roads, electricity issues, water shortages, drainage problems, and waste disposal.

## Technologies Used
- HTML
- CSS
- JavaScript
- Browser Local Storage

## Features
- Homepage displaying the purpose of the platform.
- Form for reporting community issues.
- Issue categories for organising reports.
- Reference number generation for submitted reports.
- Report tracking using reference numbers.

## How to Run the Project
1. Clone or download this repository.
2. Open the project folder.
3. Open index.html in a web browser.
4. Test the available features.

## Storage
The prototype uses browser Local Storage to save reports in the current browser. Reports are not shared across devices because the project does not yet use a central database or server.
