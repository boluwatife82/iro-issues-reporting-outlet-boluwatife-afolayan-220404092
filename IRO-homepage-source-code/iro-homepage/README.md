# IRO — Issues Reporting Outlet Homepage

Responsive frontend prototype for the IRO community issue reporting project.

## Files
- `index.html` — page structure
- `style.css` — layout, colours, responsive design
- `script.js` — demo report submission and tracking using browser localStorage

## Run it
1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. To edit, open the folder in Visual Studio Code.

No background photo is used. The hero area uses CSS gradients and a subtle grid pattern, so there is no incorrect campus image.

## Important limitations
This is a frontend prototype. Reports are stored only in the current browser on the current device. It has no shared database, server-side validation, administrator login, or production security. For a complete deployed IRO system, connect it to a backend such as Flask and a database.
